原型设置（未来并入 Rust 设置窗口）：

交互说明：悬停任意控件查看提示 · 单击行选中、任意操作后取消选中 · 双击行复制 · 行内按钮可置顶 / 复制 / 删除 · 顶栏可关闭到托盘、清空、切换窗口置顶 · 双击链接行打开浏览器、双击文件行打开资源管理器（调用路径可在上方自定义，留空用系统默认）· 点放大镜或 Ctrl+F 唤出悬浮搜索框（主窗口上方、同宽、带间距）、Esc 收起 · 悬浮类型过滤栏可按类型快速过滤（位置四向可调、图标大小可调，仅显示已有类型，可设始终显示）· 图片条目直接显示缩略图、Markdown 条目默认格式化渲染（均可在上方关闭）。
本原型与 Rust 实现逐令牌对照（theme.rs / paint.rs / solver.rs），作为「不动 Rust」阶段的功能验证底稿； 带「待移植 Rust」标注的为新增功能，确认后再统一移植。
